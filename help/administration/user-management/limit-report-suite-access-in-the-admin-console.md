# 在 [!UICONTROL Admin Console] 中限制对报表包的访问

Adobe Analytics 用户需要恰当的数据访问权限。 了解如何使用 [!UICONTROL Admin Console]，以确保用户只能访问其角色所必需的报表包。 执行 [Adobe Admin Console](https://adminconsole.adobe.com/) 中的这些快速步骤，在您的组织中创建特定于报表包的产品配置文件。
