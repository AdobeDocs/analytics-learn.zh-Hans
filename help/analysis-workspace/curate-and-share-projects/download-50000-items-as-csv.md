# 将 50000 项下载为 CSV 文件

“以 CSV 形式下载项目”选项可让您下载自由格式表中某个维度的最多 50,000 个项目，并且已应用区段和筛选器。 虽然 UI 在分页前将继续显示最多 400 个项目，但此选项允许您访问 Analysis Workspace 以外的更多数据行。

>[!VIDEO](https://video.tv.adobe.com/v/40385/?quality=12&learn=on)

有关更多信息，请参阅[文档](https://experienceleague.adobe.com/docs/analytics/analyze/analysis-workspace/curate-share/download-send.html?lang=zh-Hans)。
