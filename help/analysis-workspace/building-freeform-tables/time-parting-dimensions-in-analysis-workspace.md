# Analysis Workspace 中的[!DNL Time-parting]维度 {#time-parting-dimensions-in-analysis-workspace}

[!DNL Time-parting]会采用所收集的点击量的时间戳，并将其划分为更有意义的维度，例如“每天时间”或“每周时间”。 Analysis Workspace 中提供这些维度。
