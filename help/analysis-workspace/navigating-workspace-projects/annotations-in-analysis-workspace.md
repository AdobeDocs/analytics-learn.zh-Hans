# Analysis Workspace 中的注释

Workspace 注释使您能够有效地将上下文数据的细微差别和洞察传达给整个组织的用户。 您可以用已知的数据问题、公共假日、活动启动等批注日期或日期范围，以便更好地告知用户他们为什么会看到折线图、表格等中的相关内容。
